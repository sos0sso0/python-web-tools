📊 Excel文件合并

将多个Excel文件合并成一个文件，支持多种合并方式。

下载Python脚本

下载以下脚本到您的本地计算机：

📥 下载 excel_merge.py

使用说明：

  1. 确保您的计算机已安装Python 3.x版本
  2. 安装所需依赖：pip install pandas openpyxl
  3. 下载 excel_merge.py 文件到您的电脑
  4. 准备好需要合并的Excel文件，放在同一个文件夹中
  5. 运行脚本：python excel_merge.py
  6. 按照提示选择要处理的文件
  7. 处理结果将保存在 D:\pyOutput 目录中
注意： 所有文件处理均在您的本地计算机上完成，不会上传任何数据到服务器，确保您的数据安全。
